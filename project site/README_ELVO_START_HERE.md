# ELVO — стартовый пакет для сайта ЖК «Белогорье»

## Что внутри
- `CLINE_MASTER_PROMPT.md` — основной промпт для Cline.
- `PROJECT_BRIEF.md` — тексты, структура, поведения и перечень изображений.
- `references/` — исходные PDF и облегчённые изображения-референсы, чтобы быстро сравнивать макет.
- `public/images/` — извлечённые из дизайн-макета фотографии и два дополнительных кадра галереи.

## Как использовать
1. Распакуй содержимое в корень текущего проекта в VS Code. Если у тебя уже есть файл с тем же именем, не перезаписывай его, пока не проверишь содержимое.
2. Открой `CLINE_MASTER_PROMPT.md` и отправь его содержимое в Cline. Убедись, что расширение Cline смотрит именно на папку проекта.
3. Выбранная модель GLM 5.3 Flash должна быть настроена в Cline через OpenRouter. Не добавляй API-ключ OpenRouter в исходники сайта.
4. Попроси Cline сначала проверить существующий проект, затем реализовать, запустить сборку и проверить интеракции.
5. После работы проверь в браузере desktop и mobile, особенно модалку формы и слайдер.

Форма демонстрационная: данные не отправляются и не сохраняются. База данных, backend и API для этой версии не нужны.
