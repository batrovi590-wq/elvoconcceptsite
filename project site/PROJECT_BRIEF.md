# ЖК «Белогорье» — содержание и поведение лендинга

## Тип проекта
Одностраничный концептуальный лендинг жилого комплекса бизнес-класса в Сочи. Это портфолио-концепт ELVO Digital Studio, не настоящий оффер по продаже недвижимости.

### Преимущества
1. Архитектура в гармонии с природой — Натуральные материалы, выразительные формы и внимание к деталям.
2. Пространство и свет — Продуманные планировки и панорамные виды.
3. Комфорт в деталях — Эстетика, которая чувствуется в мелочах.

- Заголовок: Продуманная эстетика для каждого вашего дня.

## Главные действия
- Nav links smoothly scroll to the corresponding sections on the same page.
- Header «Связаться с нами» opens the modal.
- Hero CTA scrolls to the project/philosophy section.
- «Смотреть интерьеры» scrolls to the carousel.
- Carousel arrows and dots change the active image.
- All links and buttons need a meaningful action; no `href="#"` placeholders.
